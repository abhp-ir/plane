Unmodified static fonts from Amiri 1.003, licensed under SIL Open Font License 1.1 (see OFL.txt).

Source: https://github.com/aliftype/amiri/releases/tag/1.003
Archive: https://github.com/aliftype/amiri/releases/download/1.003/Amiri-1.003.zip
Archive SHA256: `81af0aff7d2086d8af24cea7202f7546130997982534691373485cd96744d05e`

React-pdf needs static font faces. These fonts supply missing Arabic-script glyphs, including Persian letters, with regular, bold, italic and bold italic faces. Inter remains the first choice for document text; Courier remains the first choice for code. No runtime font download is needed. The web font configuration is separate.
