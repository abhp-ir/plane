# Vazirmatn

Unmodified variable WOFF2 from [Vazirmatn v33.003](https://github.com/rastikerdar/vazirmatn/tree/v33.003),
`fonts/webfonts/Vazirmatn[wght].woff2`. Weight axis: 100–900. Copyright and SIL Open Font
License 1.1 are retained in [OFL.txt](./OFL.txt).

`../persian.css` uses the Arabic-script glyph ranges only for Persian UI. Latin falls back
to Plane's Inter, code keeps its monospace font, and other locales keep their font tokens.
The asset is served by Vite alongside the existing bundled fonts; no CDN or runtime download service is used.
